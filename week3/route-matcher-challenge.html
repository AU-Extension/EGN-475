Route matcher challenge

Twenty quick questions in three parts: which view function answers a URL, what HTML a Jinja snippet produces, and what url_for() builds. These are exactly the details Copilot gets wrong most often, so learning to predict them makes you a much better reviewer of its code.

How to use this interactive
  1. Choose the app you are building (the questions use its routes and data).
  2. Read the route table on the right. It stays visible for every question.
  3. Pick one answer per question. You get feedback and an explanation right away.
  4. Each question is worth 5 points. At the end you see your score and a review of anything you missed.
  5. Retake it as often as you like. Aim for 90 or more before you start Assignment 3.1.

    Rules to remember

    • <int:x> matches digits only. A plain <x> matches any text without a slash.
    • When both could match, the more specific int rule wins.
    • A rule ending in / redirects the no-slash version (308). A rule without the slash gives 404 if you add one.
    • If the path matches but the method is not allowed, Flask answers 405.
    • url_for() takes the function name, not the URL. Missing route values cause a BuildError; extra values become a query string.
    • Jinja prints a missing variable as nothing, but reading an attribute from it raises an error.
