Flask request lifecycle

Type a URL and follow the request through your Flask app: the route table picks a view function, the view sends data to a Jinja template, and the finished HTML travels back to the browser. Try the broken URLs too, because seeing a 404 happen step by step makes it much easier to fix one.

How to use this interactive
  1. Pick the app you are building this term: Option A (café) or Option B (salon).
  2. Click one of the example URLs or type your own path after the address.
  3. Press "Send request" to play the whole journey, or "Next step" to move one station at a time.
  4. Read the highlighted code at each station and the explanation under it.
  5. Turn on "Forget to pass data to render_template()" and send the same requests again to see which pages break loudly and which fail silently.
