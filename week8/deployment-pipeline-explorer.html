Deployment pipeline explorer

Deploying means putting your prototype on a server so anyone with the link can use it. Follow the eight stages from your laptop to a live PythonAnywhere site, then practice reading the errors that break a first deployment.

How to use this interactive
  1. Press Play the deploy to watch the whole pipeline once, or click any stage to open it.
  2. Each stage shows where you work (laptop, GitHub, or PythonAnywhere), the exact commands or settings, and a check to confirm it worked.
  3. Replace yourusername with your PythonAnywhere username and egn475-cafe-perez with your own repository name.
  4. In What broke?, open each scenario, read the symptom and the error log, and see which stage holds the fix.
  5. Finish with the quick check at the bottom.

The pipeline

Color tags show where each step happens: Laptop GitHub Bash console Web tab

What broke?

First deployments almost always break once. On PythonAnywhere the browser only says "Something went wrong". The real answer is in the error log: Web tab, then the Log files section, then the file ending in .error.log. The newest lines are at the bottom.
