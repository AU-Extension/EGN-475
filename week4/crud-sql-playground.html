CRUD SQL playground

Every button in your prototype runs one SQL statement. Here you can create, read, update, and delete rows in a practice table and see the exact db.execute() call, with ? placeholders and parameters, that your Flask view would send to SQLite. Then try the unsafe version and watch a SQL injection happen.

How to use this interactive
  1. Pick your table: menu_items for the café or services for the salon.
  2. Use the tabs to add a row, filter the list, edit a row, or delete one. The row buttons in the table work too.
  3. After every action, read the statement panel: the SQL, the parameters, and what SQLite did.
  4. Open the "Search and injection" tab, switch to the unsafe f-string version, and try the example inputs.
  5. Press "Reset table" whenever you want the starting data back. Nothing here touches a real database.
