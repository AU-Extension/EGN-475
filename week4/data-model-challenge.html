Data model challenge

Before Copilot writes a single CREATE TABLE, you decide what your prototype needs to remember. Pick the tables, place each column, choose keys and data types, and then find the mistakes in a schema an assistant suggested. You finish with a model schema.sql to compare against your own.

How to use this interactive
  1. Choose your option. Switching restarts the challenge with that app's data.
  2. Work through the four steps in order. Each step has a "Check this step" button that scores it and explains every answer.
  3. Points: tables 20, columns 30, keys and types 30, schema review 20.
  4. At the end, compare the model schema with what you plan to write for Assignment 4.1.

Vocabulary

  • A table stores one kind of thing; each row is one of them.
  • A primary key (id) gives every row a unique number.
  • A foreign key stores another table's id to link rows together.
  • Store money as whole cents in an INTEGER, never as a decimal number.
  • SQLite has no true/false type: use INTEGER 1 or 0.
