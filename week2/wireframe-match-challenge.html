Wireframe match challenge

A wireframe is only useful if every user story has a screen that supports it. Match stories to screens, find what is missing, and put a booking flow in order. Your score is out of 100.

How to use this interactive
  1. Part 1 (30 points): for each café story, choose the wireframe screen that supports it, then check.
  2. Part 2 (40 points): each wireframe is missing one element its story needs. Pick it.
  3. Part 3 (30 points): put the salon booking screens in the order a client uses them.
  4. Read the explanation after each answer. These are the same checks you will run on your own wireframes in Assignment 2.2.
