Test runner simulator

Copilot is good at drafting tests for the happy path. This simulator shows what those tests miss: switch on realistic bugs, run the suite, and add the edge-case tests that catch them.

How to use this interactive
  1. Choose your option: café order board or appointment booker.
  2. Press Run pytest with no bugs switched on. The Copilot draft suite passes.
  3. Switch on one or more bugs in the code panel and run again. Notice how many bugs the draft suite lets through.
  4. Add tests from the list of edge cases until your suite catches all six bugs. Try to do it without adding tests that catch nothing new.
  5. Read the failure output for each red test. It has the same layout you will see in VS Code when you run pytest.
