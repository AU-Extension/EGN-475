Post, redirect, get: how a Flask form really works

Submit a form in the mock browser and watch every request and response travel to the Flask server and back. Then press refresh and see why a missing redirect can send the kitchen a duplicate order.

How to use this interactive
  1. Choose your project option (café or salon). The form and the Flask code change to match.
  2. Fill in the form, or leave a field empty on purpose, and press the submit button.
  3. Watch the server panel: the highlighted code line is the one running now, and the blue box explains it.
  4. After a successful submit, press "Refresh (F5)" and compare what happens in each mode.
  5. Switch to "No redirect" mode and repeat. Check the database table for duplicates.
